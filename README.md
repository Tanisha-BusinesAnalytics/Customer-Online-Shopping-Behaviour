# Customer-Online-Shopping-Behaviour
This project analyzes customer behavior in an online shopping environment using Power BI. The dashboard provides insights into user demographics, purchasing patterns, device usage, and spending habits to help businesses understand customer preferences and improve decision-making.
Key Highlights
👥 Total Users: 999
💸 Avg Monthly Spend: 6.89K
🔁 Return Rate: 19%
🛍 Most Purchased Categories: Clothing, Electronics, Groceries
